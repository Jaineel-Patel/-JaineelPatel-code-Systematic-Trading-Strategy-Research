# -JaineelPatel-code-Systematic-Trading-Strategy-Research


## Overview

This project explores systematic equity trading strategies using historical market data from Yahoo Finance.

The current version implements a simple momentum strategy across a basket of U.S. equities. Stocks are held when their 20-day return is positive and performance is compared against a buy-and-hold benchmark.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance

## Current Features

- Historical data download
- Momentum signal generation
- Look-ahead bias prevention
- Portfolio backtesting
- Benchmark comparison
- Equity curve visualisation
